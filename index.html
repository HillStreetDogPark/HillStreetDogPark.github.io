PERSONAL ACCOUNT UTILITY

Personal Cloud
Change Monitor

A private record of changes to the owner's cloud files.

What it does

The monitor checks file and folder metadata on an hourly schedule and compares it with a saved inventory. It identifies additions, changes to modification metadata, moves, renames, trash transitions and removals. Reports appear as issues in the owner's private GitHub repository and follow the owner's GitHub email notification settings.

Google Drive access

The Google Drive integration requests only drive.metadata.readonly. It reads file IDs, names, folder relationships, modification times, sizes and checksums where available. It does not read file contents or create, edit, delete or share Drive files.

Personal use only

This is a single-user utility operated by its account owner. It is not a public registration service. This website provides information only; it does not connect visitors' accounts or display any file inventories, reports or credentials.

Data and control

OAuth credentials are kept as encrypted GitHub Actions secrets. Metadata inventories and reports are stored in a private GitHub repository. The owner can pause the monitor, revoke Google access or remove stored data. Read the privacy notice for details.

For support, use the operator's support email displayed on the Google authorization screen. Only the owner is an intended user.

PERSONAL CLOUD CHANGE MONITOR

Use of this utility

An owner-operated tool for a single personal account.

Intended use

Personal Cloud Change Monitor is maintained for its owner's personal cloud metadata monitoring. It is not offered as a commercial service and does not accept registrations or payments. Visiting this information site does not authorize access to any account.

Account authorization

Only the owner should authorize an account they control. The Google Drive monitor uses read-only metadata access. The owner controls authorization, notification destinations, private storage, and retention. Provider permissions and service terms continue to apply.

Reporting limits

Reports compare saved inventories and do not provide a complete audit history. Changes that are undone between checks can be absent. Provider delays, revoked permissions, outages, scheduling delays and quota limits can interrupt checks. A removal may mean a deleted file or lost access. The tool is not a backup or a file recovery service.

Stopping use

The owner can disable the schedule and revoke account authorization at any time. Stored inventories and reports must be removed separately as described in the privacy notice. No additional public service agreement or support commitment is offered by this information site.

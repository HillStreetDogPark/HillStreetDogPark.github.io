PERSONAL CLOUD CHANGE MONITOR

Privacy notice

This utility processes metadata for its owner's personal change reports.

Access and use

With the owner's consent, the monitor accesses Google Drive metadata using the read-only metadata scope. Data can include file and folder IDs, names, parent relationships, modification times, sizes, checksums and trash or removal status. It uses this information to build an inventory, compare subsequent changes, and produce reports. Removals can represent deleted items or loss of access. File contents are not downloaded.

Storage and service providers

Checks run in GitHub Actions. Metadata inventories, change cursors and issue reports are stored in the owner's private GitHub repository. OAuth client credentials and refresh tokens are stored as encrypted GitHub Actions secrets and used to access Google APIs. GitHub delivers report notifications according to the owner's settings, including to the selected email provider. Google, GitHub and the email provider process data as part of these services under their own terms and privacy policies.

Retention and removal

The current inventory is replaced on successful checks, but older inventories can remain in private Git history, and reports can remain in issues and email. There is no automatic retention deadline. The owner controls deletion of repository history, issues, credentials and emails. Pausing or revoking access stops future checks but does not erase existing copies. Hosted service providers may retain backups or logs under their policies.

Choices and security

The owner can pause checks through the repository's activation setting, revoke access at Google Account connections, and remove the monitor's secrets and stored data. Repository access must remain private. No cloud credentials, file names or reports are published on this website.

Limited use

The monitor does not sell Google user data, use it for advertising, or use it to train general-purpose AI models. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The data is used only for the personal monitoring function described here.

This information site

This site has no account forms, analytics scripts or tracking cookies added by the operator. GitHub Pages hosts it and may process ordinary request information under GitHub's privacy policy. Questions about the utility can be directed to the operator's support email shown on the Google consent screen.
